# 📖 Project Overview

Insider trading activity can provide valuable insights into a company's internal sentiment. Corporate executives, directors, and key employees are required to report their stock transactions to the SEC.

This project analyzes those insider transaction records and presents meaningful statistics through company-wise summaries and visualizations.

The application processes **859,000+ insider transaction records**, allowing users to search for any company using its stock ticker and instantly view transaction insights.

# ⚙️ Installation

Clone the repository

```bash
git clone https://github.com/KarthikNukala7/insider-transactions-analysis.git
```

Move into the project

```bash
cd insider-transactions-analysis
```

Install dependencies

```bash
pip install -r requirements.txt
```

---

# ▶️ Run the Project

